# Security and Responsible Research Policy

## Purpose

This repository is a historical security-research record for the Glovo Rider Android application. It is not an official Glovo repository and is not a channel for attacking or testing Glovo production systems.

## Responsible disclosure

Security findings documented here were reported to the affected company before public publication. The disclosure timeline is documented in [`README.md`](./README.md) and [`VERIFICATION.md`](./VERIFICATION.md).

## Reporting new vulnerabilities

If you independently discover a currently exploitable vulnerability affecting Glovo or another third party, report it through that vendor's official security or vulnerability-disclosure channel before publishing sensitive technical details.

Do not post unpatched secrets, credentials, personal data, access tokens, or operational exploit material in this repository's public issue tracker.

## Research principles

The public project is intended to demonstrate:

- analysis of mobile application architecture and security controls;
- documentation of findings and remediation history;
- responsible vendor notification before publication;
- preservation of a public technical record after remediation.

The project is not intended to facilitate unauthorized access, persistence, service disruption, credential theft, or misuse of third-party data.

## Independence

`RiderUnmasked` is independently maintained and is **not affiliated with, endorsed by, or maintained by Glovo**.
